# LW

I'm building **[JustSVG](https://github.com/lwxyfer/justsvg)**, an open-source, SVG-native editor for architecture diagrams, flowcharts and infographics.

Start from a blank canvas, an example or an existing SVG. Edit in the browser and keep the result as standard SVG with editable text, shapes and groups. There's also an optional AI Skill for drafting diagrams in your own AI tool.

[Try the editor](https://justsvg.vercel.app/editor) · [Editable examples](https://justsvg.vercel.app/examples) · [Source](https://github.com/lwxyfer/justsvg) · [Diagram starter kit and downloads](https://github.com/lwxyfer/justsvg/releases/tag/v1.0.0-beta.1)

[![JustSVG editor](https://raw.githubusercontent.com/lwxyfer/justsvg/main/docs/images/editor.png)](https://justsvg.vercel.app/editor)

我在做 **JustSVG**：用原生 SVG 画架构图、流程图和信息图的开源 draw.io 替代选择。

从空白画布、示例或已有 SVG 开始，在浏览器里修改文字、图形和位置，再导出标准 SVG。也可以在自己的 AI 工具中使用独立 Skill 生成初稿，导入后精修。

在线编辑无需注册。欢迎试用、复用示例，以及在[项目 Issues](https://github.com/lwxyfer/justsvg/issues) 中提交可复现的导入、文字编辑和连线反馈。
